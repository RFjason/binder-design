# 入围阈值标定与候选池质量评估（2026-11-05）

本分析不重跑任何推理，只用两份公开数据回答两个问题：

1. `config/scoring_protocol_v1.json` 里 `ipsae_min >= 0.6` 这条线定得合不合适。
2. 当前 1,127 条候选的分数水平，与已知能结合的设计相比处于什么位置。

数据来源：Anthropic 公开的 `cofold_predictions.parquet`（逐种子逐预测器）与
`design_summary.csv`（1,440 条设计的真实湿实验结果）。
取 `cofolding_model=ef2full`、设计靶点、设计复合物化学计量，**每个设计取单个种子**，
与本仓库 `best_of_seed_selection: false` 的设置一致。

## 一、先排除一个混淆项

Anthropic 公布的 `ipsae_min_ef2full` 是 5 个种子取最大，本仓库用单种子。
若两者差距大，就不能直接拿他们的数做标定。实测：

**单种子与 5 种子取最大之差，中位 0.012，均值 0.050。** 差距很小，可以直接比。

## 二、0.6 这条线定得是合适的

| 阈值 | 留住真结合体 | 留存率 | 混入非结合体 | 命中率 |
|---|---|---|---|---|
| 0.50 | 326/354 | 92% | 618 | 34.5% |
| 0.55 | 316/354 | 89% | 578 | 35.3% |
| **0.60** | **309/354** | **87%** | **535** | **36.6%** |
| 0.65 | 298/354 | 84% | 475 | 38.6% |
| 0.70 | 279/354 | 79% | 415 | 40.2% |

**0.6 能留住 87% 的真结合体**，属于偏宽松的一侧。
往下放到 0.5 只多留 5 个百分点的召回，却要多放进 83 条非结合体。
**结论是不要为了凑候选数量去放松这条线，它不是瓶颈。**

## 三、瓶颈在候选池本身

| | ipsae_min |
|---|---|
| Anthropic 真结合体中位（单种子，n=354） | **0.798** |
| Anthropic 非结合体中位（单种子，n=966） | 0.642 |
| 本仓库 1,127 条的**最大值** | **0.698** |
| 本仓库 99% 分位 | 0.629 |
| 本仓库中位 | 0.000 |

**当前最好的一条候选（0.698），低于已知真结合体的中位数（0.798），
也只略高于已知非结合体的中位数（0.642）。**

逐靶点看，真结合体的单种子中位数分布如下：

| 靶点 | 化学计量 | 真结合体 | 中位 ipsae_min |
|---|---|---|---|
| BHRF1 | 1to1 | 23 | 0.894 |
| PD-L1 | 1to1 | 39 | 0.886 |
| IL-7Rα | 1to1 | 49 | 0.848 |
| TrkA | 1to1 | 20 | 0.847 |
| TREM2 | 1to1 | 72 | 0.811 |
| RBX1 | 1to1 | 28 | 0.794 |
| EGFR | 1to1 | 10 | 0.783 |
| Nipah-G | 1to1 | 19 | 0.759 |
| VEGF-A | 1to2 | 54 | 0.703 |
| TNF-α | 1to3 | 12 | 0.691 |

TNFR1 与上表前八个同为单链靶点。那些靶点上真结合体的中位在 0.76 至 0.89 之间。

⚠️ **适用范围**：`INSILICO.md` 明确写明 ipSAE「不可跨靶点、跨化学计量、跨预测器比较」。
TNFR1 不在 Anthropic 的靶点集中，所以上面的对比是**提示性的，不是判定性的**。
但 1to1 靶点之间的量级一致性足以说明方向。

## 四、建议

1. **保持 0.6 不变。** 标定显示它偏宽松，不是当前「19 条过线、0 条可提交」的原因。
2. **把精力放在提高候选质量上，而不是放宽筛子。** 最好的一条还低于已知真结合体的中位。
3. **优先排查 RFantibody 这一路。** 357 条设计 0 条过线，而 RFD4 的 520 条过 4 条、
   BindCraft2 的 250 条过 15 条。三路差异这么大，更像是该路线的配置或表位设置有问题，
   而不是设计本身都不行。
4. 表位选择值得复核。当前分 crd2 与 crd3 两个层，两层的产出率可以单独统计一下。
