# TNFR1 成熟核心复评

[已完成的复评与分簇结果](results/README.md)

赛事表达构建已更新为 P19438-1 Leu30–Thr211，靶蛋白带 C 端 His-tag。本实验在 **182 aa 无标签原生核心** 上复评。His-tag 长度、连接肽和实验固定方式未给出，因此结果不能回答标签或固定表面是否遮挡。输出中的末端和糖基化位点距离仅用于排查近端姿态。

固定队列为 v1 初筛通过的 21 个候选：历史批次 19 个、本轮 2 个。历史 19 个补齐框架末端 IMGT S128，分数差同时包含 VHH 修正和靶点输入变化。其余 2 个 VHH 序列不变，直接比较 M1–T211 与 L30–T211 输入（各用对应的靶点 MSA）。这批复评不计为新增设计序列，也不改写 v1 的任何结果。

- 复评：每条 VHH 做一个成熟核心复合物预测和一个 VHH 单体预测。ESMFold2 Full、seed 0、1 sample、无模板、无初始猜测、只有复合物中的靶点用 MSA。沿用双方向取较小值的 ipSAE（d0res，PAE/距离阈值 10 Å）和 v1 计算初筛门槛。DockQ 以同一设计的原始成熟核心姿态为参照。
- 历史分簇：在同一设计表位内，用 CRD2（84–125）或 CRD3（127–166）窗口对齐 v1 预测结构的靶链，再比较 VHH 共有的 83 个框架 Cα 的 RMSD。接触指纹为距 VHH 重原子 4.5 Å 内的成熟 TNFR1 残基。组内任意一对接触 Jaccard ≥0.5，主分析 RMSD ≤3 Å，并报告 2/5 Å 的敏感性。分簇代表按 v1 ipSAE 选取，供后续筛选参考。
- 资源：1 个 A800、2 小时上限；另有 1 个 20 分钟 CPU 分簇任务。若 CPU 分区未恢复，GPU 批次在开始推理前也能产出分簇；两边共用结果锁。推理逐个保存成功记录，失败保留诊断。复评的 GPU 分配纳入主项目账本。

用 `python prepare.py <TNFR1_mature_L30_T211.a3m> <新暂存目录>` 重建输入包。历史候选来自主仓库的两个冻结快照，输入 MSA 从本轮实际使用的文件提供，SHA-256 及对齐行数见 `submission/protocol.json` 和 `submission/provenance.json`。预测与结构分析入口仅在 Slurm 计算节点上运行。
