# TNFR1 VHH：累计约5,000条的扩展轮次

用户于2026-11-06授权将正式候选池扩大到约5,000条。基线为首轮已评分的1,127条；本轮最多新增3,873条去重后正式候选。对照、接口试跑及重复序列不计入目标。

## 配额和执行

- RFD4主探索：两表位×两组CDR长度，每组38批×20条，共3,040条独立采样。
- BindCraft2：两表位各50条独立轨迹，共100条；保留梯度终点和ProteinMPNN重设计输出。
- 优选亲本CDR重采样：6条亲本×3个温度×20序列，共360次采样，保留亲本ID。
- RFantibody补充：4批×4骨架×4序列，最多64条。
- RFD4备用：32批×20条，共640条，主批次结束后仅在尚未达到目标时使用。

配额是采样上限；不同序列的全局注册表只接收最多3,873条新增候选。完成一批立即提取、去重、独立评分，不等待全部生成结束。新增序列与原1,127条精确去重；同一亲本的序列变体不作为新骨架计数。

各路线先用与生产相同的脚本完成接口试跑和评分审计，成功后自动放行该路线。接口试跑要求合法输出和评分链路完整，不要求必须出现高分候选。

调度器`MaxSubmitJobs=500`，因此按任务0–99、100–199、200–273、274–305四波提交；上一波生成、评分和审计全部结束后由CPU控制任务自动接续下一波，同一时间最多约402项作业。最后一波是备用。

2026-11-06提交时A100的首批预计启动时间在11月12日，A800在11月6日下午，因此本轮GPU任务选择A800。它只有4张卡，实际并行数还受共享队列限制；6个生成与2个评分是上限。

同伴审计指出旧坐标框架缺IMGT S128。本轮生成仍使用已验证的原始结构条件，在提取时为成熟序列补齐S128，随后对完整新序列重新做复合物和单体预测。原1127条也按补尾后的序列注册去重，单纯补尾不计作新设计。设计参考结构保留真实解析残基，DockQ只对齐有坐标的残基；末端补位没有伪造参考坐标。

## 计算与保护

最多6个生成GPU任务和2个评分GPU任务。每项生成时限45分钟、评分30分钟；CPU提取/审计20分钟。生成进程必须确认GPU后端，BC2优先加载自身NVIDIA库并设置`JAX_PLATFORMS=cuda`，不允许CPU回退。

本轮预计新增约90–110 GPU小时；项目累计硬上限200 GPU小时，包含此前74.1967小时故障与有效计算。预留7小时覆盖在途作业和启动开销，达到193小时停止启动新GPU阶段。Slurm实际记账为主要依据，终止但未写结束元数据的作业也计入。

持续CPU监控只管理本轮已登记作业ID：周期刷新Slurm成本和进度，发现重复错误时停止相应路线的未启动生成任务；达到候选目标时取消本轮尚未启动的生成任务，保留在途输出与评分。

## 评分与终审

主评分沿用首轮的ESMFold2 Full、seed0、1 sample、无模板、无初始猜测、仅靶标MSA、双向ipSAE较小值。初筛门槛保持ipSAE≥0.6、单体pLDDT≥70、DockQ≥0.23、单体二硫键几何通过。

扩量不意味着原创性、完整糖链可及性或实验验证已经完成。校准和原创性工作在仓库已有独立分支推进，本轮保留这些状态并与其分开记录，不修改首轮不可变快照。

## 文件与复现

当前提交状态见`RUN_STATE.md`，初始证据见`provenance/submitted_20261106/`。该目录的`campaign_before_queue_update.json`已与原生预检中的配置哈希匹配；当前`config/campaign.json`只调整了GPU分区。
